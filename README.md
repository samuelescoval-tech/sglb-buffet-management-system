# SGLB – Sistema de Gestão de Licitações e Buffet
Sistema acadêmico para gerenciamento de licitações, cardápios, logística e operações de buffet.

## Sobre o Projeto

O SGLB (Sistema de Gestão de Licitações e Buffet) foi desenvolvido como projeto acadêmico durante a disciplina de Prototipagem de Sistemas do curso de Análise e Desenvolvimento de Sistemas.

O objetivo do projeto é modelar e prototipar um sistema capaz de auxiliar o gerenciamento de processos relacionados a:

* Licitações
* Propostas comerciais
* Planejamento operacional
* Cardápios
* Logística
* Execução de eventos
* Controle financeiro
