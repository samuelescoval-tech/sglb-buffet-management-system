# Diagramas do Projeto SGLB

## Objetivo

Representar a modelagem e os fluxos do Sistema de Gestão de Licitações e Buffet (SGLB), desenvolvido durante a disciplina de Prototipagem de Sistemas.

## Diagramas

### 01 - Caso de Uso
Representa os atores e funcionalidades principais do sistema.

### 02 - Diagrama de Sequência
Representa a comunicação entre os componentes do sistema.

### 03 - Diagrama de Classes
Representa a estrutura das entidades e seus relacionamentos.

### 04 - Fluxograma Vertical
Representa o fluxo detalhado do processo operacional.

### 05 - Fluxograma Horizontal
Representa a interação entre os setores envolvidos no processo.

## Ferramentas Utilizadas

- Lucidchart
- UML
- GitHub
- Claude AI
