# Protótipo SGLB – Sistema de Gestão de Licitações e Buffet

## Sobre

Esta pasta contém os artefatos de prototipagem desenvolvidos durante a disciplina de **Prototipagem de Sistemas** do curso de **Análise e Desenvolvimento de Sistemas**.

O projeto tem como objetivo modelar e prototipar um sistema para gerenciamento de processos relacionados a licitações, planejamento operacional, logística, cardápios e execução de eventos de buffet.

## Conteúdo

### 01 - Documento de Requisitos

Documento contendo o levantamento inicial dos requisitos do sistema, regras de negócio e funcionalidades propostas.

### 02 - Protótipo SGLB

Protótipo navegável desenvolvido para demonstrar a interface e o fluxo operacional do sistema.

### 03 - Apresentação do Projeto

Material utilizado para apresentar a proposta, a modelagem e os resultados obtidos durante o desenvolvimento do projeto.
